# vssadmin

Shows current volume shadow copy backups and all installed shadow copy writers and providers. The following table lists the available `vssadmin` commands. Select a command name to view its syntax.

| Command | Description | Availability |
|--|--|--|
| [vssadmin delete shadows](vssadmin-delete-shadows.md) | Deletes volume shadow copies. | Client and Server |
| [vssadmin list providers](vssadmin-list-providers.md) | Lists registered volume shadow copy providers. | Client and Server |
| [vssadmin list shadows](vssadmin-list-shadows.md) | Lists existing volume shadow copies. | Client and Server |
| [vssadmin list shadowstorage](vssadmin-list-shadowstorage.md) | Lists volume shadow copy storage associations. | Client and Server |
| [vssadmin list volumes](vssadmin-list-volumes.md) | Lists volumes eligible for shadow copies. | Client and Server |
| [vssadmin list writers](vssadmin-list-writers.md) | Lists all subscribed volume shadow copy writers on the system. | Client and Server |
| [vssadmin resize shadowstorage](vssadmin-resize-shadowstorage.md) | Resizes the maximum size for a shadow copy storage association. | Client and Server |
